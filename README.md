# MyIdeaProof

Статическая визитка платформы MyIdeaProof.

## Запуск

Откройте `index.html` в браузере. Backend и база данных не требуются.

Ссылка на платформу используется в CTA-кнопках и сейчас ведет на:
`https://sargeras197.github.io/contacts/`

Чтобы заменить ее, обновите значение `href` у CTA-ссылок в `index.html`.
