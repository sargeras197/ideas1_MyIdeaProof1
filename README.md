# MyIdeaProof

Статическая визитка платформы MyIdeaProof.

## Запуск

Откройте `index.html` в браузере. Backend и база данных не требуются.

Ссылка на платформу используется в CTA-кнопках и временно ведет на:
`https://sargeras197.github.io/under_development/`

Контакты автора доступны отдельно:
`https://sargeras197.github.io/contacts/`

Чтобы заменить временную заглушку, обновите значение `href` у CTA-ссылок в `index.html`.
